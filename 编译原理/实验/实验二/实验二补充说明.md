# 结合实验二的任务给出语法规则以及相应的上下文无关文法说明

## 1. 明确目标语言的语法规则

结合简单函数绘图语言的功能需求，明确核心语法结构及合法格式，具体如下。

*   **程序（Program）：** 由一个或多个语句组成，语句间用分号分隔，程序以 EOF 结束。
*   **语句（Stmt）：** 支持两类语句 —— 函数定义语句（FuncDef）和绘图指令语句（PlotStmt）。
*   **函数定义（FuncDef）：** 格式为 `func 函数名(参数名) = 表达式`，例如 `func f(x) = x^2 + 3.14`。
*   **绘图指令（PlotStmt）：** 格式为 `plot 函数名(参数名) range [最小值, 最大值]`，例如 `plot f(x) range [0, 10]`。
*   **表达式（Expr）：** 支持 `+`、`-`、`*`、`/`、`^` 五种运算符，包含整数、浮点数、标识符（变量 / 函数参数）、括号嵌套表达式，例如 `(x + 5) * 2^3`。
*   **语法约束：** 运算符需符合优先级与结合性规则，括号需成对匹配，语句结束需加分号。

## 2. 设计上下文无关文法

根据上述语法规则，设计无歧义、无左递归的上下文无关文法，核心产生式如下：

### 1. 程序与语句相关产生式：

*   **Program** $\rightarrow$ **StmtList EOF** （程序由语句列表和结束符组成）
*   **StmtList** $\rightarrow$ **Stmt ; StmtList | $\varepsilon$** （语句列表由分号分隔的语句组成，支持空列表）
*   **Stmt** $\rightarrow$ **FuncDef | PlotStmt** （语句分为函数定义和绘图指令）
*   **FuncDef** $\rightarrow$ **KEYWORD(func) IDENTIFIER LPAREN IDENTIFIER RPAREN OPERATOR(=) Expr** （函数定义规则）
*   **PlotStmt** $\rightarrow$ **KEYWORD(plot) IDENTIFIER LPAREN IDENTIFIER RPAREN KEYWORD(range) LBRACKET Number COMMA Number RBRACKET** （绘图指令规则）

### 2. 表达式相关产生式（处理优先级与左递归）：

*   **优先级分层（从低到高）：** Expr（加减） $\rightarrow$ Term（乘除） $\rightarrow$ Factor（幂运算、原子项）
*   **Expr** $\rightarrow$ **Term Expr'**
*   **Expr'** $\rightarrow$ **OPERATOR(+) Term Expr' | OPERATOR(-) Term Expr' | $\varepsilon$** （左结合，处理加减运算）
*   **Term** $\rightarrow$ **Factor Term'**
*   **Term'** $\rightarrow$ **OPERATOR(\*) Factor Term' | OPERATOR(/) Factor Term' | $\varepsilon$** （左结合，处理乘除运算）
*   **Factor** $\rightarrow$ **Atom OPERATOR(^) Factor | Atom** （右结合，处理幂运算）
*   **Atom** $\rightarrow$ **IDENTIFIER | Number | LPAREN Expr RPAREN** （原子项：标识符、常量、括号表达式）
*   **Number** $\rightarrow$ **INTEGER | FLOAT** （常量：整数或浮点数）

**终结符说明：** `KEYWORD(func)`、`KEYWORD(plot)` 等为词法分析器输出的 **Token** 类型，`IDENTIFIER`、`INTEGER`、`FLOAT` 等均对应词法单元类型。
