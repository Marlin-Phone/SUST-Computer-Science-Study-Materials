结合实验一的任务给出词法规则以及相应的正则表达式说明

1. 明确目标语言的词法规则

根据简单函数绘图语言的设计需求，定义以下词法规则，各类 Token 的具体说明如下：

*   **关键字：** 表示语言内置指令的特殊单词，不可作为标识符使用。包括 plot（绘图指令）、func（函数定义指令）、range（范围定义关键字）。
*   **标识符：** 用于表示函数名、变量名的符号，由字母开头，后跟字母或数字组成，长度不限。例如 f、g1、x2 等。
*   **常量：** 分为整数和浮点数。整数为纯数字序列（如 123、0）；浮点数包括两种形式：带整数部分的浮点数（如 3.14、100.）和不带整数部分的浮点数（如 .5、.123）。
*   **运算符：** 用于实现算术运算和赋值操作，包括 +（加法）、-（减法）、*（乘法）、/（除法）、^（幂运算）、=（赋值）。
*   **分隔符：** 用于分隔不同语法成分的符号，包括 (（左括号）、)（右括号）、,（逗号）、;（分号）。
*   **空白字符：** 包括空格、制表符（\t）、换行符（\n），仅用于分隔 Token，本身不生成 Token，需在扫描过程中过滤。

2. 为每个 Token 设计正则表达式

按照优先级从高到低的顺序（特殊符号 > 关键字 > 标识符/常量 > 空白字符），为每种 Token 设计正则表达式，具体如下表所示：

| Token 类型           | 正则表达式             | 说明                                       |
| :------------------- | :--------------------- | :----------------------------------------- |
| 关键字（KEYWORD）    | `plot                  | func                                       | range`                                         | 精确匹配预定义的关键字，优先级高于标识符 |
| 浮点数（FLOAT）      | `\d+\.\d*              | \.\d+`                                     | 匹配带小数点的数字，包括 3.14、.5、100. 等形式 |
| 整数（INTEGER）      | `\d+`                  | 匹配纯数字序列，如 123、0 等               |
| 运算符（OPERATOR）   | `[\+\-\*/\^=]`         | 匹配算术运算符和赋值符，注意“-”需转义      |
| 左括号（LPAREN）     | `\(`                   | 匹配左括号，需转义                         |
| 右括号（RPAREN）     | `\)`                   | 匹配右括号，需转义                         |
| 逗号（COMMA）        | `,`                    | 匹配逗号分隔符                             |
| 分号（SEMICOLON）    | `;`                    | 匹配语句结束符分号                         |
| 标识符（IDENTIFIER） | `[a-zA-Z][a-zA-Z0-9]*` | 字母开头，后跟字母或数字，优先级低于关键字 |
| 空白字符（SKIP）     | `\s+`                  | 匹配空格、制表符、换行符，扫描时跳过       |
| 错误字符（MISMATCH） | `.`                    | 匹配所有未定义的字符，用于抛出词法错误     |
