# 简单函数绘图语言词法分析器构造实验报告模板

## 一、实验目的

1. 理解词法分析器在编译过程中的核心作用，明确其作为编译“第一关”将源代码字符串分解为词法单元（Token）的基本功能。
2. 掌握简单函数绘图语言的词法规则定义方法，能准确划分关键字、标识符、常量、运算符、分隔符等词法单元类型。
3. 学会为不同类型的 Token 设计对应的正则表达式，理解正则表达式在词法模式匹配中的应用原理。
4. 能够使用至少一种编程语言（如 Python）实现词法分析器的核心逻辑，完成从输入源代码到 Token 序列的转换，并具备基本的错误处理能力。
5. 培养问题分析与解决能力，强化模块化编程思维，为后续语法分析、语义分析等编译环节打下基础。

## 二、实验原理

词法分析是编译过程的第一个阶段，其本质是对源程序进行扫描，按照预先定义的词法规则，将连续的字符序列分解为具有独立语义的最小语法单位——词法单元（Token），同时过滤掉无关的空白字符和注释。

实验的核心原理包括：

1. **词法单元分类**：根据简单函数绘图语言的功能需求，将词法单元划分为关键字、标识符、常量（整数、浮点数）、运算符、分隔符等类型，每种类型对应特定的语义功能。
2. **正则表达式匹配**：利用正则表达式描述每种 Token 的模式，通过正则匹配实现对源程序字符序列的识别。正则表达式需遵循“最长匹配”和“优先级排序”原则（如关键字优先级高于标识符，避免关键字被误识别为标识符）。
3. **词法分析器工作流程**：①从源程序中按顺序读取字符；②用预定义的正则表达式匹配当前位置的字符序列，找到最长匹配的 Token；③生成包含 Token 类型和值的二元组；④跳过空白字符，重复上述过程直至源程序结束；⑤若遇到无法匹配的字符，抛出词法错误。

## 四、实验步骤

### 4.1 明确目标语言的词法规则

根据简单函数绘图语言的设计需求，定义以下词法规则，各类型 Token 的具体说明如下：

*   **关键字**：表示语言内置指令的特殊单词，不可作为标识符使用。包括 `plot`（绘图指令）、`func`（函数定义指令）、`range`（范围定义关键字）。
*   **标识符**：用于表示函数名、变量名的符号，由字母开头，后跟字母或数字组成，长度不限。例如 `f`、`g1`、`x2` 等。
*   **常量**：分为整数和浮点数。整数为纯数字序列（如 `123`、`0`）；浮点数包括两种形式：带整数部分的浮点数（如 `3.14`、`100.`）和不带整数部分的浮点数（如 `.5`、`.123`）。
*   **运算符**：用于实现算术运算和赋值操作，包括 `+`（加法）、`-`（减法）、`*`（乘法）、`/`（除法）、`^`（幂运算）、`=`（赋值）。
*   **分隔符**：用于分隔不同语法成分的符号，包括 `(`（左括号）、`)`（右括号）、`,`（逗号）、`;`（分号）。
*   **空白字符**：包括空格、制表符（`\t`）、换行符（`\n`），仅用于分隔 Token，本身不生成 Token，需在扫描过程中过滤。

### 4.2 为每个 Token 设计正则表达式

按照优先级从高到低的顺序（特殊符号 > 关键字 > 标识符/常量 > 空白字符），为每种 Token 设计正则表达式，具体如下表所示：

| Token 类型          | 正则表达式             | 说明                                                 |
| :------------------ | :--------------------- | :--------------------------------------------------- |
| 关键字 (KEYWORD)    | `plot                  | func                                                 | range` | 精确匹配预定义的关键字，优先级高于标识符 |
| 浮点数 (FLOAT)      | `\d+\.\d*\|\.\d+`      | 匹配带小数点的数字，包括 `3.14`、`.5`、`100.` 等形式 |
| 整数 (INTEGER)      | `\d+`                  | 匹配纯数字序列，如 `123`、`0` 等                     |
| 运算符 (OPERATOR)   | `[+\-*/^=]`            | 匹配算术运算符和赋值符，注意 “-” 需转义              |
| 左括号 (LPAREN)     | `\(`                   | 匹配左括号，需转义                                   |
| 右括号 (RPAREN)     | `\)`                   | 匹配右括号，需转义                                   |
| 逗号 (COMMA)        | `,`                    | 匹配逗号分隔符                                       |
| 分号 (SEMICOLON)    | `;`                    | 匹配语句结束符分号                                   |
| 标识符 (IDENTIFIER) | `[a-zA-Z][a-zA-Z0-9]*` | 字母开头，后跟字母或数字，优先级低于关键字           |
| 空白字符 (SKIP)     | `\s+`                  | 匹配空格、制表符、换行符，扫描时跳过                 |
| 错误字符 (MISMATCH) | `.`                    | 匹配所有未定义的字符，用于抛出词法错误               |

### 4.3 构造词法分析器的核心逻辑

词法分析器的核心逻辑基于正则表达式匹配，主要包括以下模块：

*   **Token 类**：用于封装每个词法单元的类型和值，便于后续处理。
*   **Lexer 类**：包含源程序代码、当前扫描位置、Token 规则列表等属性，提供 `get_next_token()` 方法实现词法扫描。
*   **正则表达式拼接**：将各 Token 的正则表达式按优先级拼接为一个完整的模式，使用命名组便于识别匹配到的 Token 类型。
*   **扫描流程**：从当前位置开始匹配正则表达式，根据匹配结果生成 Token、移动扫描位置，跳过空白字符，直至源程序结束或遇到错误字符。

### 4.4 代码实现

（附 Token 类和 Lexer 类等关键模块代码）

```python
import re

class Token:
    """词法单元类，存储类型和值"""
    def __init__(self, type_, value):
        self.type = type_
        self.value = value

    def __repr__(self):
        return f"Token({self.type!r}, {self.value!r})"

class Lexer:
    """词法分析器"""
    def __init__(self, code):
        self.code = code  # 输入的源代码
        self.pos = 0      # 当前字符位置
        self.length = len(code)

        # 定义 Token 规则：(类型, 正则表达式), 按优先级排序
        self.token_specs = [
            ('KEYWORD',    r'plot|range|func'),     # 关键字 (优先级高于标识符)
            ('FLOAT',      r'\d+\.\d*|\.\d+'),      # 浮点数
            ('INTEGER',    r'\d+'),                 # 整数
            ('OPERATOR',   r'[+\-*/^=]'),           # 运算符
            ('LPAREN',     r'\('),                  # 左括号
            ('RPAREN',     r'\)'),                  # 右括号
            ('LBRACKET',   r'\['),                  # 新增：左方括号
            ('RBRACKET',   r'\]'),                  # 新增：右方括号
            ('COMMA',      r','),                   # 逗号
            ('SEMICOLON',  r';'),                   # 分号
            ('IDENTIFIER', r'[a-zA-Z][a-zA-Z0-9]*'), # 标识符
            ('SKIP',       r'\s+'),                 # 空白字符 (跳过)
            ('MISMATCH',   r'.'),                   # 匹配所有其他字符 (错误)
        ]

        # 拼接正则表达式，使用命名组便于识别类型
        self.pattern = '|'.join(f'(?P<{name}>{pattern})'
                                for name, pattern in self.token_specs)

    def get_next_token(self):
        """获取下一个词法单元"""
        while self.pos < self.length:
            # 从当前位置匹配
            match = re.match(self.pattern, self.code[self.pos:])
            if not match:
                raise SyntaxError(f"词法错误: 无法识别字符 '{self.code[self.pos]}'")

            # 获取匹配结果
            type_ = match.lastgroup
            value = match.group()
            self.pos += len(value)  # 移动位置

            # 处理空白字符 (跳过)
            if type_ == 'SKIP':
                continue
            # 处理错误字符
            if type_ == 'MISMATCH':
                raise SyntaxError(f"词法错误: 非法字符 '{value}'")

            return Token(type_, value)

        # 到达输入末尾，返回结束标记
        return Token('EOF', None)
```
