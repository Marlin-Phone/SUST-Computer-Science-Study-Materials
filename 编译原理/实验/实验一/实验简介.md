# 简单函数绘图语言词法分析器的设计与实现

## 一、实验目的

1. 理解词法分析器在编译过程中的核心作用，明确其作为编译“第一关”将源代码字符串分解为词法单元（Token）的基本功能。
2. 掌握简单函数绘图语言的词法规则定义方法，能准确划分关键字、标识符、常量、运算符、分隔符等词法单元类型。
3. 学会为不同类型的 Token 设计对应的正则表达式，理解正则表达式在词法模式匹配中的应用原理。
4. 能够使用至少一种编程语言实现词法分析器的核心逻辑，完成从输入源代码到 Token 序列的转换，并具备基本的错误处理能力。
5. 培养问题分析与解决能力，强化模块化编程思维，为后续语法分析、语义分析等编译环节打下基础。

## 二、实验原理

词法分析是编译过程第一个阶段，其本质是对源程序进行扫描，按照预先定义的词法规则，将连续的字符序列分解为具有独立语义的最小语法单位——词法单元 (Token)，同时过滤掉无关的空白字符和注释。

实验的核心原理包括：
1. **词法单元分类：** 根据简单函数绘图语言的功能需求，将词法单元划分为关键字、标识符、常量（整数、浮点数）、运算符、分隔符等类型，每种类型对应特定的语义功能。
2. **正则表达式匹配：** 利用正则表达式描述每种 Token 的模式，通过正则匹配实现对源程序字符序列的识别。正则表达式需遵循“最长匹配”和“优先级排序”原则（如关键字优先级高于标识符，避免关键字被误识别为标识符）。
3. **词法分析器工作流程：** ①从源程序中按顺序读取字符；②用预定义的正则表达式匹配当前位置的字符序列，找到最长匹配的 Token；③生成包含 Token 类型和值的二元组；④跳过空白字符，重复上述过程直至源程序结束；⑤若遇到无法匹配的字符，抛出词法错误。

## 三、实验要求

1. 明确简单函数绘图语言的词法规则，至少涵盖关键字（如 plot、func、range）、标识符（函数名、变量名）、常量（整数、浮点数）、运算符（+、-、*、/、^、=）、分隔符（(、)、,、;）等词法单元。
2. 为每种 Token 设计正确的正则表达式，确保能准确区分容易混淆的 Token（如整数与浮点数、关键字与标识符）。
3. 选择实现语言，编写词法分析器代码，要求代码结构清晰、注释完整，包含 Token 类（存储 Token 类型和值）和 Lexer 类（实现词法扫描逻辑）。
4. 词法分析器需具备基本的错误处理能力，能识别非法字符并抛出明确的词法错误提示（如“词法错误：非法字符'#'”）。
5. 设计至少 3 组测试案例（含正常输入、含空白/注释、含非法字符），验证词法分析器的功能正确性，并记录输出结果。
    - **测试案例 1：** sin(x) + 2*cos(3.14)
    - **测试案例 2：** draw x = x*x + log(10) - 0.5
    - **测试案例 3：** a1 = 123 + tan(45)/exp(2)
    - **测试案例 4：** x = .5 + 999 - 0.001;
    - **测试案例 5：** sin(x)@ + 2#; //包含非法的符号
6. 实验报告需详细阐述实验步骤、核心代码实现及测试结果，逻辑清晰、内容完整。
