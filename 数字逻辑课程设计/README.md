## 数字逻辑课程内容

数字逻辑课程设计任务主要是 从老师给的几个选题中选择一个进行实现，我们组选择的是声控流水灯设计。  
最终考核时，将目录中的资料准备好并放在U盘里面，需要打印的打印出来，封装为袋，再将两者带到答辩现场即可。  
答辩不用演示PPT，直接演示实物效果，老师提问几个问题（两个左右），回答完后现场打分，就结束了。
